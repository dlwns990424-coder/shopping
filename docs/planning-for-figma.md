# first-shop 기획서 / 스타일가이드 / IA (Figma 작업용 참고문서)

## 1. 기획서

**프로젝트명**: first-shop
**목적**: 포트폴리오 + React/Supabase 학습
**타겟 사용자**: 20~40대 남녀, 댄디하고 심플한 패션을 선호하는 층
**컨셉**: 심플하고 깔끔한 미니멀 스타일

**핵심 기능 요약**
- 이메일/비밀번호 회원가입·로그인 (Supabase Auth, 소셜로그인 없음)
- 상품 조회 (MEN/WOMEN, 카테고리별)
- 장바구니 담기 (로그인 사용자 기준 DB 저장)
- 가상 결제 (PG 연동 없이 버튼 클릭 시 즉시 "결제완료" 주문 생성)
- 마이페이지에서 본인 주문 내역/상태 확인
- 관리자: 상품 등록/수정/삭제, 주문 상태 변경(결제완료→상품준비중→배송중→배송완료), 회원 목록 확인, 매출 통계 확인
- 관리자가 주문 상태를 바꾸면 사용자 마이페이지에 즉시 반영

**범위 제외 (의도적으로 안 만드는 것)**
- 실제 PG 결제 연동
- 소셜 로그인
- 리뷰/평점, 위시리스트, 쿠폰/할인 등 부가 기능 (범위 밖)

## 2. IA (Information Architecture)

### 사용자 사이트맵
```
/ (HOME)
├── /men (MEN)
│   └── /products/:id (상품 상세)
├── /women (WOMEN)
│   └── /products/:id (상품 상세)
├── /cart (장바구니)
├── /order (주문/결제)
├── /mypage (마이페이지 - 주문 내역/상태)
├── /login (로그인)
└── /signup (회원가입)
```

### 관리자 사이트맵 (사용자 영역과 완전 분리)
```
/admin
├── /admin/products (상품관리 - 등록/수정/삭제)
├── /admin/orders (주문관리 - 상태 변경)
├── /admin/members (회원관리 - 목록/기본정보)
└── /admin/sales (매출관리 - 전체 매출/건수/기간별 통계)
```

### 사용자 흐름 (User Flow) 핵심 경로
1. 비회원 → HOME → 상품 목록(MEN/WOMEN) → 상품 상세 → (로그인 유도) → 로그인/회원가입 → 장바구니 담기
2. 회원 → 장바구니 → 주문페이지 → 가상 결제 → 마이페이지에서 주문 상태 확인
3. 관리자 → 로그인(관리자 권한) → 주문관리 → 상태 변경 → (사용자 마이페이지 즉시 반영)

### 화면 단위 (Figma 프레임 기준 제안)
- 공통: 헤더(로고/GNB/장바구니 아이콘/로그인), 푸터
- HOME, MEN 목록, WOMEN 목록, 상품 상세, 장바구니, 주문/결제, 마이페이지, 로그인, 회원가입
- 관리자: 상품관리(목록+등록/수정 폼), 주문관리(목록+상태변경), 회원관리(목록), 매출관리(대시보드)
- 반응형 기준: PC(1280px~) / 태블릿(768px~) / 모바일(~767px) — 3단계 브레이크포인트 권장

### 폰트 (제안)
- 한글: Pretendard
- 영문: Inter 또는 Archivo
- 최대 2종만 사용 (본문/제목 굵기 차이로 위계 구분)

### 카테고리 (제안)
- 상의 / 아우터 / 하의 / 신발 / 액세서리
- MEN/WOMEN 공통 구조 (DB `products` 테이블에 `gender`, `category` 컬럼으로 구분)

> 위 세 항목(컬러/폰트/카테고리)은 확정된 것이 아니라 참고용 추천안입니다. Figma에서 실제로 배치해보면서 최종 결정하시면 되고, 결정되는 대로 알려주시면 코드에 반영하겠습니다.
