# NOVERA

남성·여성 컬렉션과 카테고리별 상품 탐색을 중심으로 구성한 의류 쇼핑몰입니다. 상품 이미지를 강조한 화면과 반응형 레이아웃을 적용하고, 관리자가 배너와 상품 진열을 직접 변경할 수 있도록 구현했습니다.

## 1. 프로젝트 소개

### 제작 목적

프론트엔드부터 백엔드(Supabase)까지 직접 설계·구현하며 실제 서비스에 가까운 쇼핑몰을 완성해보고 싶어 시작한 개인 프로젝트입니다.
단순 CRUD를 넘어, 회원 인증·장바구니·주문·리뷰·반품까지 실제 커머스에서 필요한 플로우를 끝까지 구현하는 것을 목표로 했습니다.

### 핵심 기능

- **사용자:** 상품 탐색·검색, 위시리스트, 장바구니·주문, 마이페이지
- **관리자:** 상품·주문·회원·매출·콘텐츠 관리

## 2. 개발 개요

- **개발 기간:** 2026.09.03 ~ 2026.09.23
- **개발 인원:** 1명
- **담당 범위:** 서비스 기획, UI 디자인, 프론트엔드 개발, Supabase 데이터베이스·인증·접근 정책 설정, 배포

## 3. 기술 스택

| 구분              | 기술                               | 사용 목적                                             |
| ----------------- | ---------------------------------- | ----------------------------------------------------- |
| 프론트엔드        | React                              | 컴포넌트 기반 화면 구성                               |
| 언어              | TypeScript                         | 타입 정의 및 코드 안정성 확보                         |
| 빌드 도구         | Vite                               | 개발 서버 및 프로젝트 빌드                            |
| 스타일링          | Tailwind CSS                       | 유틸리티 클래스 기반 스타일링, 반응형 대응            |
| 데이터베이스·인증 | Supabase (Postgres, Auth, Storage) | 회원 인증, 상품·주문 데이터 저장, RLS 기반 접근 제어, |
| 배포              | Vercel                             | 프론트엔드 빌드 결과물 배포 및 호스팅                 |

> 실제 결제는 연동하지 않았으며, 주문 생성과 배송·반품·환불 상태 관리 흐름을 구현했습니다.

#### 상품 관리

#### 회원 관리

## 5. 프로젝트 회고

### 기획과 리서치의 중요성

초기 기획에서 기능 범위와 화면 구조, 구현에 필요한 기술을 충분히
정리하지 못했습니다. 개발 도중 레퍼런스 사이트와 이미지를 추가로
조사하면서 초기 기획과 와이어프레임이 반복적으로 변경되었습니다.

이 과정을 통해 화면을 구현하기 전에 사용자 흐름과 기능별 요구사항을
구체적으로 정리하는 것이 중요하다는 점을 배웠습니다.

다음 프로젝트에서는 레퍼런스 조사와 IA, 주요 화면의 와이어프레임을
먼저 정리하고, 필수 기능과 추가 기능을 구분해 개발을 시작하려고 합니다.
개발 중 변경이 필요한 경우에는 변경 이유와 영향을 받는 화면을 기록해
작업 범위를 관리하겠습니다.
