## 1. 프로젝트 소개

### 제작 목적

프론트엔드부터 백엔드(Supabase)까지 직접 설계·구현하며 실제 서비스에 가까운 쇼핑몰을 완성해보고 싶어 시작한 개인 프로젝트입니다.
단순 CRUD를 넘어, 회원 인증·장바구니·주문·리뷰·반품까지 실제 커머스에서 필요한 플로우를 끝까지 구현하는 것을 목표로 했습니다.

### 핵심 기능

- **사용자:** 상품 탐색·검색, 위시리스트, 장바구니·주문, 마이페이지
- **관리자:** 상품·주문·회원·매출·콘텐츠 관리

### 관리자

<img width="1000" alt="상품관리,주문관리" src="https://github.com/user-attachments/assets/7f514dae-d019-4f96-afb3-4db7c09774f3" />

#### 상품 관리

- 상품 등록/수정/삭제, 대표·상세·호버 이미지 업로드
- 드래그 또는 화살표 버튼으로 진열 순서 변경
- 상품별 리뷰 조회 및 삭제

#### 주문 관리

- 주문 목록 조회 및 배송상태 변경(개별/일괄)
- 반품 신청 접수 → 환불 완료 처리
- 주문 상세(배송지, 반품 사유·사진) 확인

<img width="1000" alt="회원관리,매출관리" src="https://github.com/user-attachments/assets/40e7b59a-5117-4210-9f46-aa7f8ccf5887" />

#### 회원 관리

- 회원 목록 조회(닉네임/이메일/전화번호 검색, 가입일·주문수·누적구매액 정렬)
- 권한 변경(일반↔관리자), 계정 정지/해제, 정보 수정
- 삭제(휴지통 이동 → 복구 또는 완전 삭제), 회원별 최근 주문 내역 확인

#### 매출 관리

- 기간별(오늘/이번 주/이번 달/전체/직접 선택) 매출·주문수·평균주문금액·취소율 KPI
- 일별 매출 추이 차트, 베스트셀러 TOP 5, 카테고리별 매출 비중
- 배송 상태별 주문 분포 확인

#### 콘텐츠 관리

- 히어로·에디토리얼 배너 텍스트/이미지/이동 경로 편집 (브레이크포인트별 크롭)
- 카테고리·서브카테고리 추가/순서변경/삭제, 카테고리 카드 이미지 관리
- 베스트 상품 스냅샷 수동 갱신

## 5. 프로젝트 회고

### 아쉬운 점

- 처음 기획을 세울때 더 정확한 기능 범위, 어떠한 기능을 구현할때 필요한 기술, IA 등 너무 미흡하여
  작업하던 도중 레퍼런스 사이트, 이미지 등 찾으면서 계속 처음 기획했던 내용 및 와이어 프레임이 자꾸 변화하였다.

  이번 프로젝트를 진행하면서 기획과 리서치가 정말 중요하다는것을 다시한번 느꼈다.
