## 3. 기술 스택

| 구분              | 기술                               | 사용 목적                                             |
| ----------------- | ---------------------------------- | ----------------------------------------------------- |
| 프론트엔드        | React                              | 컴포넌트 기반 화면 구성                               |
| 언어              | TypeScript                         | 타입 정의 및 코드 안정성 확보                         |
| 빌드 도구         | Vite                               | 개발 서버 및 프로젝트 빌드                            |
| 스타일링          | Tailwind CSS                       | 유틸리티 클래스 기반 스타일링, 반응형 대응            |
| 데이터베이스·인증 | Supabase (Postgres, Auth, Storage) | 회원 인증, 상품·주문 데이터 저장, RLS 기반 접근 제어, |
| 배포              | Vercel                             | 프론트엔드 빌드 결과물 배포 및 호스팅                 |
